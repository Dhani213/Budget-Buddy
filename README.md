# Budget-Buddy
BudgetBuddy is a simple and responsive personal finance management web application built using HTML, CSS, and JavaScript. It helps users track income and expenses, view transaction history, analyze spending patterns, and use built-in GST and EMI calculators.

# Features
Dashboard showing Total Balance, Income, and Expenses
Add and manage transactions
Transaction History with delete option
Expense Analytics with category-wise bar charts
GST Calculator
EMI Calculator
Data persistence using localStorage
Responsive glassmorphism-based UI

# Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
localStorage

# How It Works
Add income or expense transactions.
Data is saved automatically in localStorage.
Dashboard updates in real time.
Analytics shows spending breakdown.
Use GST and EMI calculators for quick financial calculations.
Use Case

This project is useful for students and beginners who want to understand DOM manipulation, event handling, localStorage, and basic financial calculations while building a practical frontend project.
